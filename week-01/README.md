# Week 01: Core Python Fundamentals & Practical Drills

This directory contains foundational Python programming exercises, real-world billing simulations, and compulsory assessment modules developed for Week 01 of the PSEB DEPLOY journey.

## Projects & Drills

1. **[Smart Canteen Discount System (`python-conditionals-smart-canteen`)](./python-conditionals-smart-canteen)**
   - **Topics**: Conditional branching (`if`, `elif`, `else`), comparison and logical operators, percentage discount tiers, membership verification, input validation with `try/except`.
   - **File**: `smart_canteen_discount.py`

2. **[Smart Electricity Bill Calculator (`python-loops-electricity-bill-calculator`)](./python-loops-electricity-bill-calculator)**
   - **Topics**: Loop structures (`for`, `range()`), loop control (`continue`), running accumulators, progressive tiered tariff calculations, statistics (max, average, successful counts), robust error handling.
   - **File**: `smart_electricity_bill.py`

3. **[Student Scholarship & Pharmacy Assessment (`python-conditions-loops-assessment`)](./python-conditions-loops-assessment)**
   - **Topics**: Input validation loops (`try/except`), boundary checks (0–100%), multi-criteria conditional branching, scholarship tier categorization, pharmacy inventory management.
   - **Files**: `student_scholarship_system.py`, `pharmacy_inventory_system.py`

4. **[Functions, Strings & Lists Assessment (`python-functions-lists-assessment`)](./python-functions-lists-assessment)**
   - **Topics**: User-defined functions (`def`, parameters, return), string sanitization (`.strip()`, `.title()`, `.isdigit()`), list operations (`.append()`, `len()`, `sum()`, `max()`, `min()`, `sorted()`), grade calculation rules, and analytical class performance reporting.
   - **Files**: `result_card_generator.py`, `class_marks_analyzer.py`

5. **[Personal Expense Tracker CLI (`python-expense-tracker-cli`)](./python-expense-tracker-cli)**
   - **Topics**: Menu-driven CLI app, continuous `while True` loop, multi-list state management (`descriptions`, `categories`, `amounts`), robust error handling, case-insensitive category filtering (`.lower()`), and statistical summaries (`sum`, `average`, `max`).
   - **File**: `expense_tracker.py`

6. **[GitHub Profile README & Setup (`github-profile-readme`)](./github-profile-readme)**
   - **Topics**: Git workflow, special profile repository configuration (`MaroofSultan17`), Markdown formatting, and 3-commit milestone cadence.
   - **Files**: `README.md`, `SETUP_GUIDE.md`

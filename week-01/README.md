# Week 01: Core Python Fundamentals & Practical Drills

This directory contains foundational Python programming exercises and real-world billing simulations developed for Week 01.

## Projects & Drills

1. **[Smart Canteen Discount System (`python-conditionals-smart-canteen`)](./python-conditionals-smart-canteen)**
   - **Topics**: Conditional branching (`if`, `elif`, `else`), comparison and logical operators, percentage discount tiers, membership verification, input validation with `try/except`.
   - **File**: `smart_canteen_discount.py`

2. **[Smart Electricity Bill Calculator (`python-loops-electricity-bill-calculator`)](./python-loops-electricity-bill-calculator)**
   - **Topics**: Loop structures (`for`, `range()`), loop control (`continue`), running accumulators, progressive tiered tariff calculations, statistics (max, average, successful counts), robust error handling.
   - **File**: `smart_electricity_bill.py`

3. **[Student Scholarship System Assessment (`python-conditions-loops-assessment`)](./python-conditions-loops-assessment)**
   - **Topics**: Input validation loops (`try/except`), boundary checks (0–100%), multi-criteria conditional branching, scholarship tier categorization (Full vs. Partial), comprehensive ineligibility reporting.
   - **File**: `student_scholarship_system.py`
